A weather forecast for a city that doesn't exist — one line, max 140 characters.

> Tomorrow in Nowhere City: sunny with a chance of Tuesdays. Expect delays on the invisible line and umbrella-optional rain.

Run `main.ts` with Node and it writes exactly that line (no trailing newline) to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).
